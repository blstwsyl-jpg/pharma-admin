# صيدلي — لوحة الإدارة

لوحة إدارة مستقلة لمنصة توصيل الأدوية، مبنية باستخدام React + Vite. تعمل منفصلة عن تطبيق العميل، وتحتوي على روابط قابلة للتعديل لتطبيق العميل وتطبيق الكابتن بعد نشر كل واحد منهما على نطاق مستقل.

## الموجود في النسخة الحالية

- لوحة نظرة عامة وإحصائيات تشغيلية.
- إدارة الطلبات وتغيير الحالة وتعيين الكابتن.
- إدارة فريق التوصيل وحالات التوفر والتقييم.
- إدارة الصيدليات والمنتجات والمخزون.
- قائمة العملاء.
- نافذة إعدادات لإدارة روابط تطبيق العميل والكابتن.
- تصميم عربي RTL متجاوب مع الهاتف والكمبيوتر.
- إعدادات جاهزة لـ GitHub Actions وVercel وNetlify.
- عميل API يقرأ الطلبات والكباتن من خادم tRPC المشترك ويحدّث الحالات والتعيين.
- مؤشر اتصال يوضح الانتقال بين البيانات الحية والوضع التجريبي عند غياب جلسة الإدارة.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

## البناء والنشر

```bash
pnpm build
```

ينتج مجلد `dist/` ويمكن نشره على Vercel أو Netlify أو GitHub Pages. عند نشر تطبيق العميل والكابتن، افتح **الإعدادات → روابط التطبيقات** داخل اللوحة، ثم استبدل الروابط التجريبية بالروابط العامة.

## ربط Manus مع GitHub

المشروع مجهز للرفع إلى GitHub عبر الفرع `pharma-admin` داخل مستودع مستقل أو داخل مستودع المنصة:

```bash
git init
git add .
git commit -m "feat: add independent pharmacy admin dashboard"
git branch -M pharma-admin
git remote add origin https://github.com/OWNER/REPOSITORY.git
git push -u origin pharma-admin
```

بعد الرفع سيعمل الملف `.github/workflows/ci.yml` تلقائياً عند كل Push أو Pull Request، ويتحقق من تثبيت الحزم وبناء نسخة الإنتاج.

## النشر عبر Vercel

- استورد مستودع GitHub.
- اختر مجلد المشروع `pharma-admin` إن كان داخل مستودع متعدد المشاريع.
- سيقرأ Vercel إعداد `vercel.json` تلقائياً.
- أمر البناء: `pnpm build`، والمجلد الناتج: `dist`.

## الربط الخلفي والمصادقة

تقرأ اللوحة `orders.adminList` و`captains.list` وتستخدم `orders.setStatus` و`orders.assign` من API المشترك. اضبط عنوان الخادم قبل النشر:

```bash
VITE_API_BASE_URL=https://api.example.com
```

يجب فتح اللوحة بجلسة مستخدم تحمل دور `admin`؛ عند غياب الجلسة تظهر الواجهة المحلية التجريبية ولا تُنفّذ العمليات الحساسة.

نظام الصلاحيات للأدوار:

- `admin`: لوحة الإدارة.
- `captain`: تطبيق الكابتن.
- `customer`: تطبيق العميل.

> يجب تفعيل المصادقة، حماية بيانات المرضى، ومراجعة متطلبات ترخيص الصيدليات والتوصيل قبل الاستخدام التجاري.
